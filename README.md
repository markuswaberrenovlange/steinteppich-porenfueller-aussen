Ein guter **Steinteppich Schutz vor Feuchtigkeit** beginnt bereits bei der richtigen Planung. Untergrund, Gefälle, Entwässerung und Materialauswahl sollten zusammenpassen.

## Steinteppich versiegeln außen: Worauf kommt es an?

Beim **Steinteppich versiegeln außen** sollte die Oberfläche zunächst sauber, trocken und frei von losen Bestandteilen sein. Eine gründliche Vorbereitung ist mindestens genauso wichtig wie das eigentliche Produkt.

Achten Sie insbesondere auf:

* einen tragfähigen und sauberen Untergrund
* passende Wetterbedingungen
* eine gleichmäßige Verarbeitung

* eine ausreichende Aushärtung vor der Nutzung

Bei größeren Flächen oder stark beanspruchten Bereichen kann eine fachgerechte Ausführung sinnvoll sein.
